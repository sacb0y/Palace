- **Procedural** files are original work made for Palace: deterministic renders from `tools/backgrounds/generate_backgrounds.py` (numpy + Pillow). No stock, traced or third-party imagery.
- **Aero** and **Bokeh** are **AI-generated** images made for Palace with Grok Bot image generation. No third-party source or reference image was used as input. They were upscaled 1280x720 -> 5120x2880 with Real-ESRGAN x4plus (realesrgan-ncnn-vulkan, BSD-3-Clause tool; the output carries no tool license), then downsampled with Lanczos to 2560x1440 and given a light grain. Sources are kept in `ai-sources/` (not shipped).
- Style references Isiac supplied were used only as a written brief, never as image inputs.
